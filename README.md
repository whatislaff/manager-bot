# Бот-менеджер для заявок на разбор

Присылает в Telegram короткое уведомление о каждой новой заявке из Google-формы:
время и кнопку «Открыть заявку», которая ведёт на ответ человека в форме.

## 1. Бот в Telegram (2 минуты)
1. Напиши @BotFather → `/newbot` → получи токен.
2. Скопируй `.env.example` в `.env` и вставь токен в `BOT_TOKEN`.

## 2. Доступ к форме (10 минут, один раз)
1. Открой https://console.cloud.google.com → создай проект (любое имя).
2. «APIs & Services» → «Library» → найди **Google Forms API** → **Enable**.
3. «APIs & Services» → «Credentials» → «Create credentials» → **Service account**.
   Имя любое, роли не нужны → «Done».
4. Открой созданный сервисный аккаунт → вкладка «Keys» → «Add key» → JSON.
   Скачанный файл положи рядом с `bot.py` под именем `service_account.json`.
5. Скопируй email сервисного аккаунта (вида `xxx@xxx.iam.gserviceaccount.com`).
6. Открой форму в редакторе → ⋮ → «Добавить соавторов» → вставь этот email как **редактора**.
   Без этого бот форму не увидит.

## 3. Настройка `.env`
- `FORM_ID`: ссылка на **редактирование** формы (`docs.google.com/forms/d/.../edit`), не публичная.
- `ADMIN_CHAT_IDS`: пока оставь пустым.

## 4. Запуск
```bash
pip install -r requirements.txt
python bot.py
```
Напиши боту `/start`, он пришлёт твой chat_id. Впиши его в `ADMIN_CHAT_IDS`
и перезапусти бота. Можно указать несколько человек через запятую.

При первом запуске бот пропускает старые ответы и дальше присылает только новые.

## Команды
- `/start` — статус бота
- `/check` — проверить форму прямо сейчас

## Чтобы работал 24/7
Бот должен где-то постоянно крутиться: подойдёт самый дешёвый VPS (Hetzner, DigitalOcean и т.п.)
или любой сервер, где уже что-то живёт. Самый простой вариант на Linux — через systemd
или `screen`/`tmux`. Файл `state.json` не удаляй: в нём бот помнит, какие заявки уже отправил.

## Если что-то не так
- **403 / The caller does not have permission** — форма не расшарена на email сервисного аккаунта.
- **Forms API has not been used in project** — не включён Google Forms API (шаг 2.2).
